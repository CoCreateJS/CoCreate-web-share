Web Share

Open the device's native share sheet with a URL and text. The user chooses an available destination. The share sheet must be opened directly from a user action, and support depends on the browser and device.

Usage

<button share share-title="A page" share-text="Take a look" share-url="https://example.com">Share</button>

On an anchor, the share trigger shares its href by default and prevents navigation. Set share-url to override it. A button defaults to the current page URL.

To share selected files, keep the file picker separate and point the share button at it with share-files-query:

<input id="files-to-share" type="file" accept="image/*" multiple>
<button share share-files-query="$document #files-to-share">Share selected files</button>

Or use actions="share" to run sharing in an action chain. Place it first in the chain to preserve the browser's user-activation window.

<button actions="share" share-title="A page" share-url="https://example.com">Share</button>
